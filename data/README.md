# Data directory

- `demo/experimental/` is the small real raw-hologram demo stored in Git.
- `remote_manifest.json` pins the private training/evaluation archives.
- `downloaded/` is created by `holod3 fetch-data` and ignored by Git.
- `.downloads/` and `.staging/` are managed caches and ignored by Git.

See [docs/data.md](../docs/data.md) for bundle contents, integrity rules, and access policy.
